# Mode toggle command (CMD 0x15) in its 1-byte form, sent from 0xAC1D.

# captures 1 and 2, each switch also set the Filter channel to High (0x0B,
# then 0x18 to the pump), whatever it had been; on this install, whose
# Touchscreen was set up by the installer, so possibly a per-install setting.
