# Heater commands - CMD 0x1A (Heater Toggle Command) and CMD 0x41 (Heater Target
# State), both sent by the Touchscreen (0x0050) to All Heaters (0x007F).
#
# Captured 2026-10-25 on lawther's install: a Connect 10 with an ICI gas heater
# (0x0074) plumbed to the spa, pump and chlorinator unplugged, so the heater
# could switch on but never fire (status "No Flow"). Apart from the first
# capture, every 0x1A/0x41 here was injected over the TCP bridge as 0x0050.
#
# The heater answers a frame that changes its state with its own CMD 0x12
# status about 0.4-0.5 s later. Idle broadcast traffic has been dropped.

# Capture 1 - "Pool" selected from Spa with the heater on. The Touchscreen

# the heater already off carries neither frame (valves.txt, Capture 3).
# ======================================================================
